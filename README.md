# Glitch Art's static hub

`hub.json`, served at https://glitchr-studio.github.io/hub.json, lists Glitch Art's open Unity packages for the
[Glitch Art Hub](https://github.com/glitchr-studio/unity-hub) (Window ▸ Glitch Art Hub ▸ Sources ▸ add this URL). Each
source is a Git package, installed by its URL; the format is in the hub's
[docs/sources.md](https://github.com/glitchr-studio/unity-hub/blob/main/docs/sources.md).
